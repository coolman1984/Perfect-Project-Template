# Full-project bug sweep — 2026-08-18

Deliberate audit of the whole template after CI went green. Method: automated
checks over syntax, encodings, round-trips, cross-file consistency and
doc/code agreement, then targeted review of each tool's logic.

**11 defects found, all fixed, each with a regression test.**

| # | Severity | Defect | Fix |
|---|---|---|---|
| 1 | High | All 9 `.bat` files shipped with LF endings. cmd.exe can mis-parse LF-only batch files, and the employee runtime is Windows-only. Contradicted the project's own `.editorconfig`. | Converted to CRLF |
| 2 | High | No `.gitattributes`, so even corrected CRLF would not survive a clone | Added, pinning `*.bat`/`*.cmd`/`*.ps1` to CRLF |
| 3 | High | `to_decimal` stripped every comma, so `1.234,56` became `1.23456` and `1,5` became `15`. Silent numeric corruption of a control total; violated Part 27.3 | Rightmost-separator rule for mixed input; `decimal_separator` for single-separator input; genuinely ambiguous text now returns None and is quarantined |
| 4 | Medium | `report_tool` approvals lookup checked only `[history]` and `[quality]`, so `storage_allowed` in `[output]` — the IT-approved storage location Part 13.5 requires — was never validated | Section-agnostic lookup |
| 5 | Medium | `_miniyaml` escaped `"` on dump but never unescaped on load, so every ledger save/load cycle added a backslash | Unescape in `_unquote`; round-trip test over 3 cycles |
| 6 | Medium | Six gates had `status: pass` but still prescribed a `next_action`, reading as unfinished work | Cleared on settled gates |
| 7 | Low | `_check_tracked_by_git` docstring promised an untracked-file warning that was never implemented | Implemented via new `git_tracked_files()` |
| 8 | Low | `map context --budget 50` returned exit 1 (real violation) instead of 2 (usage error), against Part 37.4 | Returns `EXIT_USAGE` |
| 9 | Low | README claimed "97 tests" in two places; actual count differed | Corrected to the real count |
| 10 | Low | Dead guard in `check_no_secrets`, already handled by `_scan_targets`; secret scan also lacked the docstring exemption the other scans had | Removed guard, added exemption |
| 11 | Low | `licenses/` is committed but was undocumented in the PROJECT_MAP grouped-paths table | Documented |

## What this says about the gates

All 11 survived every existing gate and three green CI runs. Gates catch what
they were written to catch; they cannot catch a rule nobody encoded. Each fix
now carries a regression test, so these specific classes cannot return
silently — but the general lesson (L-009) is that periodic whole-project sweeps
are their own activity, not a by-product of per-change checking.

Three of the eleven — #3, #4 and the earlier `.gitignore`/scanner pair — are the
same underlying mistake: handling the common case and silently mangling the
rest.
