```text

                       │                    │
```

state that does not pass through the local API (Part 0.9).

## Grouped paths

Generated, runtime, archive, database, cache, log, vendor and large input
folders are catalogued as **groups**, never one row per file (Part 20.3):

| Group | Contents | Rule |
|---|---|---|
| `runtime/` | bundled private runtime | generated; never inspected or committed |
| `offline_packages/` | hash-locked wheelhouse | developer/agent rebuild only |
| `repair_payload/` | sealed release components | employee repair only; never `pip` |
| `inbox/`, `workspace/` | intake and run staging | ignored, never committed |
| `data/`, `archive/` | DuckDB and Parquet | restricted; contains unprotected extracted data |
| `output/`, `runs/`, `logs/` | dashboards, run evidence, structured logs | retention-controlled |
| `web/vendor/` | pinned ECharts + licenses | never edited by hand; no CDN |
| `licenses/` | full third-party license texts | populated at build time; referenced from THIRD_PARTY_NOTICES.md |
