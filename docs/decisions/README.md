# Decision records

Constitution Part 16.4. Any proposed architecture or business change is recorded
here **before** it becomes active.

Required fields:

```text
Decision ID · Date · Problem · Evidence · Options considered
Proposed option · Lost capabilities · Risks · Equivalence tests
Rollback · User approval
```

It becomes active only after **explicit user approval**. An agent may draft a
record; an agent may not approve one.

Naming: `ADR-NNNN-short-title.md`.
